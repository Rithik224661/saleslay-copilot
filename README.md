# SalesLay Copilot

Versioned agency-sales intelligence agent for SalesLay.cloud. Scores leads, classifies inbound replies, drafts/rewrites/personalizes outreach, summarizes threads, assesses meeting readiness, and suggests next best actions.

This is a **git-native agent** in [GitAgentProtocol (GAP)](https://www.gitagent.sh) format:
the agent's entire identity lives in this repository as plain files — versioned,
reviewable, and forkable like any codebase. It was created with
[Architect](https://architect.new), which keeps this repository in sync with the
app it belongs to (edits made here are merged back automatically).

## Structure

| Path | Purpose |
| --- | --- |
| `agent.yaml` | Manifest: model, tools, skills, runtime limits |
| `SOUL.md` | Identity, personality, and communication style |
| `RULES.md` | Hard constraints the agent must always follow |
| `DUTIES.md` | Day-to-day responsibilities |
| `skills/<name>/SKILL.md` | One methodology per skill |
| `knowledge/` | Reference material the agent can consult |
| `memory/MEMORY.md` | Append-only long-term memory (union-merged) |

## Skills

- **lead-qualification-scoring** — Score a B2B lead 0-100 with a temperature and intent breakdown from firmographic + behavioral signals.
- **reply-classification** — Classify an inbound reply into an actionable bucket with sentiment, matching SalesLay's taxonomy.
- **outreach-copilot** — Draft, rewrite, and personalize outreach messages and suggested replies for the Unified Inbox and Campaign Builder.
- **conversation-summary** — Summarize an inbox thread into a concise brief: status, key points, contact intent, and open items.
- **meeting-readiness** — Assess whether a lead is ready to book a meeting and how to move them there.
- **follow-up-suggestion** — Recommend the single next best action for a lead with timing, channel, and a talking point.

## Editing this agent

Edit the files above directly (here on GitHub or via a clone) and the changes
merge back into the live app on its next sync. `memory/MEMORY.md` uses git's
union merge, so memory written by the running agent never conflicts with your
edits.

## Running standalone

The repo is portable — it runs anywhere with the open-source
[`@open-gitagent/gitagent`](https://www.npmjs.com/package/@open-gitagent/gitagent) runtime:

```bash
export ANTHROPIC_API_KEY=sk-...   # anthropic:claude-sonnet-4-6
npx @open-gitagent/gitagent --dir . "Hello!"
```

Inside its Architect app it runs through the owner's Lyzr account instead — no
separate model key needed there.
